# Design System Roadmap

> Abre este archivo para entender el estado completo del Design System.
> Cada fase tiene dependencias claras. Ninguna fase avanza sin completar la anterior.

---

## Visión

Medmo necesita un Design System profesional — no un UI Kit — que funcione como el **lenguaje visual oficial** del producto durante años. Este roadmap documenta cada fase de construcción, su estado actual y sus entregables.

**Regla principal:** El Design System es la única fuente de verdad. Las aplicaciones consumen; nunca redefinen.

---

## Mapa de fases

```
Principles ──→ Foundations ──→ Technical Setup ──→ Primitives ──→ Composites ──→ Patterns ──→ Templates
  (filosofía)    (tokens)        (infraestructura)   (átomos)       (moléculas)    (organismos)   (páginas)
```

**Separación fundamental:**

| Tipo | Qué es | Ejemplos |
|------|--------|----------|
| **Design Decisions** | Decisiones visuales y de diseño | Principles, Foundations, component API |
| **Technical Implementation** | Infraestructura del framework | ThemeProvider, Tailwind mapping, providers |
