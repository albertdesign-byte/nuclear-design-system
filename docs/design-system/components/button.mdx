# Button

Button ejecuta acciones inmediatas: guardar, confirmar, cancelar, eliminar o
archivar. La navegación utiliza `Link`; la selección persistente utiliza
controles de toggle.

## Public API

```tsx
<Button>Save patient</Button>
<Button variant="outline">Cancel</Button>
<Button intent="danger">Delete study</Button>
<Button loading loadingLabel="Saving patient">Save patient</Button>
<Button variant="ghost" size="icon-xl" aria-label="View report">
  <EyeIcon />
</Button>
```

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `variant` | `primary` \| `secondary` \| `outline` \| `ghost` | `primary` | Énfasis visual |
| `intent` | `default` \| `danger` | `default` | Semántica destructiva |
| `size` | `sm` \| `md` \| `lg` \| `xl` \| `xxl` \| `icon-*` | `md` | Escala |
| `loading` | `boolean` | `false` | Spinner, `aria-busy` y bloqueo de interacción |
| `loadingLabel` | `string` | `"Loading"` | Anuncio para lectores de pantalla |
| `fullWidth` | `boolean` | `false` | Ocupa el ancho del contenedor |
| `disabled` | `boolean` | `false` | Estado deshabilitado |
| `type` | `button` \| `submit` \| `reset` | `button` | Tipo nativo |

## Horizontal padding

La silueta redondeada requiere más aire horizontal que la escala anterior.
Estos valores son oficiales:

| Size | Altura | Current | Adopted |
|------|--------|---------|---------|
| `sm` | 28px | 8px | 12px |
| `md` | 32px | 8px | 12px |
| `lg` | 36px | 12px | 16px |
| `xl` | 48px | 12px | 20px |
| `xxl` | 56px | 16px | 24px |

Los tamaños `icon-*` permanecen cuadrados y no usan padding horizontal.

## Icon spacing

- Icono + label: `--space-button-icon-gap` = 6px.
- Icono leading: antes del verbo u objeto.
- Icono trailing: dirección, continuación o disclosure.
- Icon-only: `aria-label` obligatorio.
- Tamaño base: `icon-sm` (16px); el Button escala el icono según su size.

## Variants

| Estilo | Uso |
|--------|-----|
| `primary` | Única acción principal del contexto |
| `secondary` | Alternativa visible con menor prioridad |
| `outline` | Cancelar o acción secundaria en formularios |
| `ghost` | Toolbars, rows y utilidades de bajo énfasis |
| `intent="danger"` | Eliminar, quitar acceso o archivar con consecuencia |

Danger utiliza fondo rojo suave, borde rojo y texto rojo en reposo. No utiliza
fondo rojo sólido por defecto. El color comunica consecuencia sin aumentar
innecesariamente la carga visual en interfaces clínicas.

## Button groups

Button Group es un patrón documentado dentro de Button, no un componente
independiente.

```tsx
// Standard: Secondary → Primary
<div role="group" aria-label="Save patient actions">
  <Button variant="outline">Cancel</Button>
  <Button>Save patient</Button>
</div>

// Destructive: Cancel → Danger
<div role="group" aria-label="Delete study actions">
  <Button variant="outline">Cancel</Button>
  <Button intent="danger">Delete study</Button>
</div>
```

Una agrupación contiene una sola acción primaria. La acción que confirma o
produce la consecuencia aparece al final.

## States

| State | Comportamiento |
|-------|----------------|
| Default | Tokens base por `variant × intent` |
| Hover | Refuerza superficie, borde o texto |
| Focus-visible | `--color-focus-ring` y offset tokenizado |
| Active | Feedback de presión con superficie activa |
| Disabled | `--color-disabled-*`, sin opacidad global |
| Loading | Spinner, `aria-busy`, bloqueo de doble submit |

## Accessibility

- Elemento `<button>` nativo por defecto.
- Tab enfoca; Enter y Space activan.
- Focus visible en todos los variants e intents.
- Icon-only requiere un nombre accesible específico.
- `xl` (48px) y `xxl` (56px) cumplen el objetivo táctil de 44px.
- `sm`, `md` y `lg` se reservan para contextos desktop densos o deben estar
  contenidos en un target interactivo mayor.
- Loading mantiene el label visible y anuncia `loadingLabel`.

## Healthcare examples

- Primary: Save patient.
- Secondary: Upload study.
- Ghost: View report.
- Danger: Delete study.
- Danger outline: Archive record.

