# Typography

> La jerarquía se comunica con tamaño, peso y espacio — no con color.
> IBM Plex Sans Condensed es la voz tipográfica de Medmo.

---

## Typography Intent

Esta sección explica **por qué** existe el Typography System — no qué contiene.

### Typography existe para maximizar legibilidad

Medmo presenta datos clínicos, formularios complejos y tablas densas durante horas. Cada decisión tipográfica prioriza que el usuario **lea sin esfuerzo**: tamaños mínimos de 14px para UI funcional, 16px para contenido clínico, line-heights generosos (1.5+), y pesos con contraste suficiente entre body (400) y labels (500).

**Implicación:** No reducimos tamaños para "caber más datos" a nivel de componente. Eso es responsabilidad de la futura Density Foundation — no de atajos tipográficos locales.

### Debe reducir la fatiga visual en interfaces clínicas densas

Condensed no significa comprimido hasta la incomodidad. IBM Plex Sans Condensed permite más caracteres por línea **sin reducir el tamaño físico**. Usamos la condensación de la fuente, no `font-size: 12px` en body text, para ganar densidad.

**Implicación:** `body-small` (14px) es el piso funcional. `caption` (12px) y `overline` (11px) están restringidos a metadata no crítica.

### La jerarquía se comunica principalmente mediante tamaño, peso y espacio

Un H1 no es azul navy. Un label no es gris claro con color diferente al body. La distinción entre `h2` (24px/600) y `title` (18px/500) es dimensional — no cromática. El test de validación: screenshot en escala de grises; la jerarquía debe permanecer clara.

**Implicación:** Los tokens de color (`color-text-primary`, `color-text-secondary`) complementan la tipografía — nunca la reemplazan.

### IBM Plex Sans Condensed es identidad visual

No es una preferencia estética intercambiable. Es la tipografía oficial de Medmo, igual que `#242F50` es el color oficial. Geist, Inter, system-ui y cualquier otra fuente están prohibidas en la interfaz del producto.

**Implicación:** Solo el role `code` usa IBM Plex Mono. Todo lo demás usa IBM Plex Sans Condensed.

---

## Filosofía

| Principio | Aplicación |
|-----------|------------|
| **Roles, not sizes** | Componentes usan `text-h2`, nunca `font-size-2xl` |
| **Primitive → Semantic** | La escala visual es implementación interna |
| **16px body baseline** | Contenido clínico legible sin zoom |
| **Weight hierarchy** | 400 body → 500 label/title → 600 headings |
| **Monospace for data** | IDs y valores alineados usan `code` |

---

## Arquitectura

```
Primitives (interno)          Semantic Tokens (componentes)       CSS Variables
─────────────────────         ─────────────────────────────       ───────────────
font-size-3xl              →  text-h1                        →  --text-h1-size
font-weight-semibold         text-h1                        →  --text-h1-weight
line-height-tight            text-h1                        →  --text-h1-line-height
font-family-sans             text-body                      →  --text-body-font-family
```

**Regla:** Los componentes **nunca** consumen primitivos. Solo `--text-{role}-*`.

Modificar la escala completa = cambiar primitivos en `typography.css`. Cero cambios en componentes.

## Accesibilidad

| Regla | Requisito | Roles |
|-------|-----------|-------|
| Tamaño mínimo funcional | 14px | label, body-small, code |
| Body baseline | 16px | body |
| Line height mínimo | 1.5 | body, body-small, label |
| Caption restringido | 12px, no crítico | caption |
| Overline restringido | 11px, uppercase only | overline |
| Jerarquía sin color | Grayscale test | h1–h3, title |
| Datos monospace | Scan accuracy | code |

Ver `foundations/typography/accessibility.ts` para reglas completas.

## Reglas de consumo

```css
/* ✅ Correcto — semantic token */
.page-title {
  font-family: var(--text-h1-font-family);
  font-size: var(--text-h1-size);
  font-weight: var(--text-h1-weight);
  line-height: var(--text-h1-line-height);
  letter-spacing: var(--text-h1-letter-spacing);
  color: var(--color-text-primary);
}

/* ❌ Incorrecto — primitivo directo */
.page-title {
  font-size: var(--font-size-3xl);
  font-weight: 600;
}

/* ❌ Incorrecto — valor hardcodeado */
.page-title {
  font-size: 30px;
  font-family: Inter, sans-serif;
}
```

Ver `foundations/typography/rules.md` para guía completa.

## Relación con Density (planificado)

La futura Density Foundation modificará valores semánticos globalmente:

| Mode | Body size | Spacing factor |
|------|-----------|----------------|
| Comfortable | 16px | 100% (default) |
| Compact | 14px | ~85% |
| Dense | 14px | ~70% |

Los componentes seguirán consumiendo `--text-body-size` — Density cambia el valor, no el componente.
