## Metodología de auditoría

Se auditaron todos los archivos de interfaz en el repositorio:

- `src/components/ui/` — 19 componentes
- `src/lib/utils.ts` — utilidad `cn()`
- `src/app/` — layout, página principal, globals.css
- `components.json` — configuración shadcn
- `public/` — assets estáticos
- Dependencias UI en `package-lock.json`

**Alcance excluido:** `node_modules`, código de terceros.
