# Medmo Opacity System

Framework-agnostic alpha modifiers. **Intentionally minimal** — Colors owns most alpha.

## Public API (complete)

| Token | Value |
|-------|-------|
| `opacity-subtle` | 0.2 |
| `opacity-muted` | 0.6 |
| `opacity-skeleton-from` / `-to` | 0.5 → 1 |

## Not in this Foundation

Overlay, focus, disabled, hover → **Colors** (`color-overlay`, `color-focus-ring`, `color-disabled-*`)

## Token principle

Less tokens, more intention. See `foundations/token-principle.ts`.
