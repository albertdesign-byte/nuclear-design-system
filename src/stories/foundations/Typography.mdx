# Typography

Nuclear uses Poppins as the official Medmo typeface. Product components consume semantic roles (`text-display` through `text-code`), not raw font-size steps. Each role binds family, size, weight, line height, and letter spacing so a global scale change updates every heading without component edits.

Hierarchy is built with size, weight, and space. Do not paint headings in brand color to make them important. Use at most one display title per page.
