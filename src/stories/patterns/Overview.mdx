# Patterns

Patterns document composed UI blocks built from Nuclear components — field groups, shell layouts, deposit summaries, and user-flow screens.

## Documented patterns

- **Deposit Summary** — pricing breakdown for checkout and deposit screens
- **Payment Form** — card entry with Stripe badge

Additional pattern stories will be added as product screens stabilize. Reference implementations also live under `src/components/docs/` and `src/components/patients-shell/`.
