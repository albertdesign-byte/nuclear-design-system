# Screens

Screens show how a production view is assembled from existing Nuclear templates, patterns, and components. They are not new UI. They do not add tokens, primitives, or recipes.

Canonical building blocks stay where they already live: **Templates/**, **Patterns/**, and **Components/**.

## Operational

- **Dashboard** — `Screens/Operational/Dashboard`. AppShell, AppSidebar, AppHeader, Workspace tabs, DashboardGrid, and Worklist table. Demo data from existing scan-request fixtures.
- **Tasks** — `Screens/Operational/Tasks`. AppShell, Tabs, SelectField, InputField, CheckboxField, and DataTable. The column filter row uses `DataTableFilterRow`. Bulk actions and pagination are composed from existing controls.
